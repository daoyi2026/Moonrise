# Moonrise

A standalone p5.js galaxy experience prepared for embedding in My Room.

## Local preview

```sh
npm run dev
```

Then open <http://127.0.0.1:4175/>. The root page redirects to
`public/experiences/galaxy/`.

## Validation

```sh
npm run check
```

The experience uses a vendored p5.js build so it can run without a third-party
CDN dependency.
